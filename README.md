# Student-Management-System
A simple Student Management System using Java and OOP.
Features
.Add Student
.View All Students
.Search Student by ID
.Update Student Information
.Delete Student
.Menu-driven program using Switch Case

Technologies Used
.Java
.Objected-Oriented Programming(OOP)
.ArrayList
.Eclipse IDE

Concepts Practiced
.Classes and Objects
.Encapsulation
.Constructors and Methods
.Getters and Setters
.Loops and Conditional Statements
.ArrayList
.CRUD Operations

How to Run
1.Open Eclipse IDE.
2.Import the StudentManagementSystem project.
3.Open Main.java.
4.Run the program.
